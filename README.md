## Descripción
Sistema básico de gestión de pacientes del hospital Marmaja, desarrollado en C++. El proyecto implementa una simulación del flujo de pacientes utilizando programación orientada a objetos (POO), herencia, gestión de memoria dinámica, punteros, y estructuras de datos (Colas, Pilas y Listas Enlazadas).

## Requisitos Previos
* PC

## Instrucciones de Compilación (CMake / MinGW)
1. Asegúrese de tener CMake y un compilador de C++ compatible instalados en el sistema.
2. Abra una terminal en la raíz del proyecto (donde se ubica el `CMakeLists.txt`).
3. Genere los archivos de construcción ejecutando: `cmake -B build`
4. Compile el código fuente ejecutando: `cmake --build build`

## Instrucciones de Ejecución
1. Diríjase al directorio donde se generó el ejecutable.
2. Ejecute el programa (ej. `./build/T1` en Linux/macOS o `build\T1.exe` en Windows).
3. Asegúrese de que el archivo `pacientes.txt` esté ubicado en el directorio correcto de trabajo para que el programa pueda leerlo exitosamente.
